=== Демонстрація розгалуження ланцюга ===

1) Початковий стан (усі вузли синхронізовані):
   http://localhost:5001: {'difficulty': 4, 'height': 0, 'total_work': 65536}
   http://localhost:5002: {'difficulty': 4, 'height': 0, 'total_work': 65536}
   http://localhost:5003: {'difficulty': 4, 'height': 0, 'total_work': 65536}

2) Вузол C ізольований від мережі (не зареєстрований як сусід A/B, і навпаки).

3) Майнимо блок на вузлі A (розповсюдиться на B, бо вони з'єднані):
   успіх: True -> висота A: 1
   висота B після трансляції: 1
   висота C (ізольований, блок не дійшов): 0

   Даємо C намайнити один блок, щоб у miner_c з'явився баланс для транзакції:
   баланс miner_c на C: 50.0
   демонстраційна транзакція в мемпул C: 201 {'accepted': True, 'txid': 'e43e205ab0d42265bd971e4f306c3851dd2b1c2eeb7c25b0651dc7069918422d'}

4) Майнимо на ізольованому C блок, що включає цю транзакцію:
   успіх: True -> висота C: 2

   Тепер A/B мають один ланцюг, C — інший, приблизно тієї ж довжини:
   A: height=1 work=131072
   B: height=1 work=131072
   C: height=2 work=196608

5) Домайновуємо на A, доки гілка A/B не стане важчою за роботою за гілку C:
   висота A: 3  висота C: 2

6) 'Підключаємо' C назад до мережі (реєструємо сусідів) і викликаємо /nodes/resolve на C:
    {'height': 3, 'message': 'Ланцюг замінено, нова висота 3', 'replaced': True, 'returned_tx_count': 1, 'source': 'http://localhost:5002'}

7) Фінальний стан — усі вузли на одному (найважчому) ланцюзі:
   A: {'difficulty': 4, 'height': 3, 'total_work': 262144}
   B: {'difficulty': 4, 'height': 3, 'total_work': 262144}
   C: {'difficulty': 4, 'height': 3, 'total_work': 262144}

8) Мемпул C після реорганізації (має містити повернуту транзакцію): 0 транз.

Висновок: транзакція з 'програного' блоку C не зникла — вона повернулась у мемпул і буде включена в один із наступних блоків.
